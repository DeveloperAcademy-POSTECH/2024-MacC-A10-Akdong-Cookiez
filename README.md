### 🐤 해외여행, 낯선 물가에 살까 말까 고민될 땐?

소비짹은 해외여행 중에 구매가 고민되는 품목에 대해 <br>
다양한 관점(현지, 한국, 사용자의 판단 기록)의 평가를 제공해 **합리적인 지출 판단을 돕는 서비스** 입니다.

[🔗 앱스토어 바로가기](https://apps.apple.com/kr/app/%EC%86%8C%EB%B9%84%EC%A7%B9/id6738742036)


### 📆 프로젝트 진행 기간

- 전체 기간: 2024. 09. 02. - 12. 05. (3개월)<br>
- 개발 기간: 2024. 11. 12. - 12. 04. (23일)


### ⚙️ 기술 스택
- UIKit, CoreData, Unit Test
- Cocoa MVC + Clean Architecture + Coordinator PAttern
- Firebase - Firestore, Functions(TypeScript)
